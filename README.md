# Yunth 楽天スーパーSALE会場(9/10-9/11版)

`yunth-super-sale-lp-0906`(9/6-9/9版)をベースに、9月10日(木)0:00〜9月11日(金)1:59の期間限定企画用に作り直した版です。この期間は楽天スーパーSALE本編の最終日にあたります。

## 9/6-9/9版からの変更点

- **タイマー期間**: 9/6(日)0:00〜9/9(水)23:59 → **9/10(木)0:00〜9/11(金)1:59**(本編終了と同時刻)
- **タイマーラベル**: 「9/10-9/11限定！先着3000名様セット終了まで」に変更(無くなり次第終了・先着3000名様のため)
- **FV画像**: 9/10-9/11版の内容(先着3000名様・無くなり次第終了)に差し替え済みです。画像サイズが変わった(1600px幅→1200px幅)ため、「クーポン獲得はこちら」ボタンの透明クリック領域も座標を実測して再調整済みです。
- **定番アイテム上部のセールバナー**: 9/10-9/11版の画像に差し替え済みです(美顔器が7,800円OFFクーポンの案内に変更)。
- **終了後の案内文**: この期間はSALE本編と同時に終わるため、「本編は引き続き対象です」という一文は削除しました。
- **美顔器Deep Boostのバッジ・リンク**: 「24%OFFクーポン」→「7,800円OFFクーポン」に文言変更し、リンク先も新しいクーポン取得URLに更新しました。
- **画像ファイル名をこの期間専用に変更**: `images/hero/yunthss-fv.jpg` → `images/hero/yunthss-fv-0910.jpg`、`images/banner/yunth-sale-925-905.jpg` → `images/banner/yunth-sale-0910.jpg`。**過去の版と同じファイル名のまま上書きすると、ブラウザやRakutenの画像サーバー側にキャッシュが残り、画像が切り替わらないことがあるため、期間ごとに一意のファイル名にしています。** 今後さらに期間を追加する場合も、同様に画像ファイル名を毎回変えることをおすすめします。

## 納品・上書きの方法

これまでと同様、`index.html` + `images/` フォルダのみの構成です。設置済みの場所に、この一式を**フォルダごと上書き**していただければ切り替わります。

## 設定済みの内容

- **クーポン取得URL(FVのボタン)**: 設定済みです(変更なし)。
- **タイマー日時**: `CHANCE_START`(9/10 0:00)・`CHANCE_END`(9/11 1:59)に設定済みです。
